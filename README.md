# 雅各的梯子翻轉模擬器

單檔網頁（`index.html`），用純 CSS 3D 和原生 JavaScript 模擬「雅各的梯子」翻面木塊玩具，不依賴外部函式庫。

- 網址：https://ioksengtan.github.io/jacobs-ladder/
- 玩法：按住最上面一塊往上拖，放開後木塊依序翻面，畫面從 A（夏天）換成 B（秋天）；往下拖翻回來。也可按「自動翻轉」。
- 可上傳自己的 A、B 兩張圖，會自動切成 N 塊；可調木塊數量（3～12）與每塊間隔時間。
- 內建範例圖是頁面裡用 canvas 畫出來的，沒有使用任何別人的作品。
- 規格見 `SPEC.md`。

## 限制
- 只是運動學近似的外觀模擬：每塊繞自己的水平中線翻 180 度，依序延遲，不是真實的剛體物理，也沒有布帶。
- 上傳的圖會依整串木塊的長寬比拉伸填滿，不會裁切保持比例。
